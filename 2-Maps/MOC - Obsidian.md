# 🗺️ MOC - Obsidian

> [!note] Vue d'ensemble
> Cette carte de contenu rassemble les notes sur le thème : **Obsidian — l'éditeur de notes Markdown liées, son organisation en vault et les plugins qui étendent son ergonomie**

## Introduction

Obsidian est un éditeur de notes en Markdown stockées localement en fichiers plats. Sa valeur tient moins à l'éditeur lui-même qu'à ce qu'on construit dessus : des liens bidirectionnels qui font émerger un graphe de connaissances, une organisation de vault (Zettelkasten, MOC, templates), et un écosystème de plugins qui reconfigurent la saisie et l'affichage. Cette carte couvre ces trois niveaux.

## 🔍 Points clés

> [!tip] Le fichier plat est le format
> Un vault Obsidian reste un dossier de `.md` : versionnable avec Git, lisible sans l'application, portable. Tout ce qu'ajoutent les plugins doit rester compatible avec cette propriété.

> [!tip] Les plugins reconfigurent la saisie, pas le document
> LaTeX Suite écrit du LaTeX standard, le conceal ne change que l'affichage : désinstaller le plugin ne casse aucune note.
